# bbq-dashboard

## 개요
- Firebase/SSE 기반의 운영 현황판 정적 웹 저장소.
- 문서-only 정렬과 MCP 기준(Static Web + Firebase MCP + Playwright + Axe) 유지가 목표.

## 구조
- 대시보드 페이지는 루트 HTML 파일들(`index`, `dashboard`, `posdelay`, `kds`, `banktotal`)로 구성.
- 운영 기준/지침 문서는 `APP_INTENT.md`, `CODEMAP.txt`, `AI_HANDOFF.md`, `CLAUDE.md`에서 관리.
