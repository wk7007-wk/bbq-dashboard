2026-09-20 03:37 KST · Astra 설계 요청 · 근무표 도메인 초안 · Luna/매크로 금지 · Excel365↔factory only

목표

사람이 Excel 365에서 근무·할인 칸을 보고 고친다. 공장이 SOT. Excel은 매크로 없는 매개체(Power Query 표시 + Office Script 쓰기).

엔드포인트

방향HTTPpath
할인 읽기GET/schedule_promos.json
근무 읽기GET/workschedule.json
규칙 읽기GET/workschedule_rules.json
쓰기PUT/schedule_update (Bearer + If-Match)
매핑GET/PUT/schedule_excel_map.json

WAN GET base: http://125.176.112.214:2421. 쓰기는 factory localhost + token.

Excel

  • 시트: Promos / Shifts / Employees / _Meta(ETag·schema_hash)
  • 읽기: Power Query → JSON → map으로 한글 헤더
  • 쓰기: Office Script SyncToFactory → PUT schedule_update · 412 시 새로고침 후 재편집
