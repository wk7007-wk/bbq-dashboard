최우선: 2026출근.xlsm · 시트 근무표의 보기 좋은 양식(열순서·너비·색·폰트·병합·헤더·G–AW 타임라인)을 그대로 유지. 서버는 데이터 SOT, 양식은 레이아웃 SOT. 데이터만 채우고 양식은 건드리지 않는다.

엔드포인트·인증

  • GET /schedule_promos.json, /workschedule.json (WAN)
  • PUT /schedule_update — Bearer + If-Match (localhost+token)
  • map /schedule_excel_map.json · log /schedule_sync_log.json

충돌

  • 데이터: 서버 우선 (412→클라폐기·재GET·로그)
  • 레이아웃: 엑셀 양식 절대 승 (서버가 레이아웃을 쓰지 않음)

자동 리맵

서버 스키마 변경 시 양식 칸으로의 필드 매핑만 즉시 갱신. 열 추가·순서변경·병합해제 금지. 불가 필드는 스킵+로그.

엑셀 연결

  • 서버→엑셀: PQ/Script가 값만 기입 (스타일 API 금지)
  • 엑셀→서버: Office Script가 양식 컬럼에서 추출 후 PUT
  • CLI: 동일 PUT → 엑셀은 값 새로고침만
