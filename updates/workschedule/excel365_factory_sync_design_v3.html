2. 인증

  • GET: 무토큰(WAN)
  • PUT: Authorization: Bearer <token> + If-Match: <ETag>
  • Excel 토큰=스크립트 파라미터/비밀저장소. git·채팅 하드코딩 금지

3. 충돌 해결

  1. PUT + If-Match
  2. 불일치(412) → 서버 값 유지, 클라이언트는 GET으로 맞춤
  3. 거절분·사유를 schedule_sync_log.json에 기록
  4. 타임스탬프 LWW 사용 안 함

4. 자동 리매핑

  1. schema_hash 불일치 감지
  2. 휴리스틱 맵 즉시 생성·map PUT
  3. PQ/Script 핫리로드
  4. 승인/제안 없음. sync_log만

5. Excel 연결

  • 서버→Excel: Power Query 웹 GET + 자동 새로고침
  • Excel→서버: Office Script PushToFactory (또는 웹요청 버튼). VBA/COM 불가
  • CLI→서버→Excel: CLI가 동일 PUT → Excel PQ가 따라감
